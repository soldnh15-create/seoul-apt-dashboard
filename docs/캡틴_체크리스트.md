# 캡틴이 하실 일 — 체크리스트

> 여기 있는 것은 **가입·로그인·인증키**라서 직원이 대신 못 하는 일이에요. 위에서부터 순서대로 하시면 돼요.
> 인증키는 채팅에 붙여 넣지 마세요. 아래에 적힌 칸에만 넣으면 돼요.

## A. 꼭 해야 하는 것 (약 20분)

- [ ] **1. 공공데이터포털 활용신청 2개** — [data.go.kr](https://www.data.go.kr) 로그인(없으면 가입) 후 아래 두 페이지에서 "활용신청"
  - [ ] [아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)
  - [ ] [아파트 전월세 실거래가 자료](https://www.data.go.kr/data/15126474/openapi.do)
  - 활용 목적은 "웹 사이트 개발" 정도로 적으면 돼요. 보통 바로 승인돼요(승인 뒤 실제 사용까지 1~2시간 걸릴 수 있어요).
- [ ] **2. GitHub 계정** — [github.com](https://github.com) 가입 또는 로그인
- [ ] **3. 저장소 만들기** — 오른쪽 위 + → New repository → 이름 `seoul-apt-dashboard` → **Public** → Create
  - 무료 사이트(GitHub Pages)는 공개 저장소여야 해요.
- [ ] **4. 이 PC에서 GitHub 로그인** — 개발팀에게 "깃허브 로그인 준비해 줘"라고 하시면 로그인 창을 띄워 드려요. 창에서 로그인만 직접 하시면 돼요.
  - 그다음 개발팀이 코드를 올려요(올리기 전에 한 번 더 여쭤요).
- [ ] **5. 인증키를 GitHub에 넣기** — 저장소 → Settings → Secrets and variables → Actions → New repository secret
  - Name: `DATA_GO_KR_KEY` / Secret: 공공데이터포털 마이페이지의 "일반 인증키" → Add secret
- [ ] **6. Pages 켜기** — 저장소 → Settings → Pages → Source 를 **GitHub Actions** 로
- [ ] **7. 첫 실행** — 저장소 → Actions → "매일 업데이트와 배포" → Run workflow
  - 30분~1시간쯤 뒤 `https://<아이디>.github.io/seoul-apt-dashboard/` 에서 열려요. 그 뒤로는 매일 새벽 4시 30분에 저절로 갱신돼요.
